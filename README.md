# mvBayes

![](logo.png)

A MATLAB implementation of the multivariate Bayesian regression (mvBayes) framework. Decomposes a multivariate/functional response using a user-specified orthogonal basis decomposition, and then models each basis component independently using an arbitrary user-specified (univariate) Bayesian regression model. Includes prediction and plotting methods.


## Examples
* [Friedman Example](example.m) - An extension of the "Friedman function" to functional response. The Bayesian regression model here is BASS (Bayesian Adaptive Smoothing Splines)

### Basis types

`basisType` may be:

| value        | basis                                                        | notes |
|--------------|--------------------------------------------------------------|-------|
| `"pca"`      | principal components (default)                               | `nBasis` optional |
| `"bspline"`  | cubic B-splines, interior knots at quantiles of the index     | `nBasis` required, >= 3; uses `spcol` |
| `"legendre"` | Legendre polynomials of degree 1 ... `nBasis`                 | `nBasis` required, rounded up to even |
| `"custom"`   | a basis you supply via `customBasis` (k x nMV)                | orthonormalized if it is not already |
| `"pns"`      | principal nested spheres                                      | requires fdasrvf |

### Parallel fitting

Pass `nCores` to fit the independent component models in parallel:

```matlab
fit = mvBayes(@bass, X, Y, 'basisType', 'bspline', 'nBasis', 10, 'nCores', 4);
```

`nCores` is clamped to the number of components and to the cores on the
machine. Parallel fitting uses `parfor`, so it requires the Parallel Computing
Toolbox; without it the fit runs serially. `predict` also accepts `nCores`, but
leave it at 1 unless `bayesModel`'s own `predict` is single-threaded.

### Dependencies

Core functionality requires the Statistics and Machine Learning Toolbox
(`sobolset`, `scramble` for Sobol' sampling).

`basisType="bspline"` uses `spcol` from the Curve Fitting Toolbox. Without that
toolbox it falls back to an equivalent Cox-de Boor recursion, so the B-spline
basis works either way.

`nCores > 1` requires the Parallel Computing Toolbox; without it, fitting runs
serially.

Two optional features require external packages on the MATLAB path:

* `basisType="pns"` requires [fdasrvf_MATLAB](https://github.com/jdtuck/fdasrvf_MATLAB)
  (`fastpns`, `fastPNSe2s`, `PNSs2e`).
* Closed-form Sobol' indices for BASS models require
  [bass_matlab](https://github.com/sandialabs/bass_matlab) (`BassBasis`,
  `sobolBasis`). Without it, `mvSobol` falls back to Monte Carlo.

### Tests

```matlab
results = runtests('tests')     % or: buildtool test
```

`tests/BasisTest.m` checks the basis constructions against reference values in
`tests/data/basisReference.mat`, generated by the Python implementation
(`mvBayesPy` v1.0.4) and, for the B-spline basis, directly by `patsy.bs`. It
also verifies that the `spcol` and fallback code paths agree.
